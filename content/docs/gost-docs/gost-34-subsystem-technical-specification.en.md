A partial technical specification (ЧТЗ) for developing the «Troya i K» Warehouse Network automated information system («Сеть складов «Троя и К»»). It covers general information, the goals of the development, the automation objects, requirements for the system, its functions and support subsystems, the scope and order of work, testing and acceptance, and documentation requirements. The appendices list the connected warehouses and show how the system components exchange data.

{{< callout context="note" icon="outline/info-circle" >}}
The document is available in Russian only.
{{< /callout >}}

- **Standard:** GOST 34 set of standards for automated systems
- **Document code:** П.Ж.00002 01 ЧТЗ 01
- **Size:** 46 sheets
